CASH COMPASS — QUESTION BANK (wording + context)
Generated from src/items/bank/*.ts in nishaanthjay/BFF-Cash-Compass.

WHAT THIS IS
Cash Compass is a financial-literacy diagnostic for grades 6–8, run once at the start of a BFF of America chapter workshop.
Students answer multi-step money problems, one screen per step. "Lock answer" is final: no back button, no feedback, no timers,
no points. A typed number box is always available beside any slider/tap input, and there are no default values.
The facilitator gets a live "where is the gap?" dashboard to decide what to teach first.
There are 26 problem files (25 problems; S11 is split into S11A and S11B). A session draws 5 random problems, 5 chosen by the
facilitator, or all of them.

STATUS OF THE WORDING
All wording below is DRAFT (every item has draft: true), written from the "Interaction and Admin Visual Spec". It is meant to be
replaced with approved wording before results are used for anything beyond workshop teaching.

HOW TO READ EACH ENTRY
- Scenario: what the student sees before the steps.
- Each STEP is one screen. The prompt is the exact student-facing wording. "Input" is how the student answers.
- "Correct" is the value the answer is graded against (answers within ±1% count as correct unless noted).
- "Predicted wrong answers" are common mistakes the app auto-codes (code name, value). Code meanings are listed at the end.
- "Decision" is what the facilitator is told to take from the charts. "Notes" are honest-limit caveats.
- Student sees no correct answers or explanations at any point; the Correct/Predicted/Decision lines are facilitator-side only.

MODULES: Skill & bias (S1–S15), Feasibility (F1–F8), Hybrid (H1–H2)
Item-order rules: random within modules (seeded by student code), with rules like S6 before H1, S11A/S11B at least 5 items apart,
F1 away from S4/S5. S11 order and the S12 anchor (high/low/none) are balanced by a hash of the student code.
